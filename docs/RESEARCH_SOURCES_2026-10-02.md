# Research sources used for the accuracy architecture

## Financial ML evaluation integrity
- Faraz Rana, *Evaluation Integrity in Machine Learning for Finance* (SSRN, 2026): https://papers.ssrn.com/sol3/Delivery.cfm/7007079.pdf?abstractid=7007079&mirid=1&type=2
  - Supports pipeline-aligned leakage audits, purging/embargoing, CPCV, DSR/PBO diagnostics and reproducibility controls.
- Zulfiqar Ali Mir & Dipesh Shrestha, *Quantifying Backtest Overfitting from Information Leakage* (SSRN, 2026): https://papers.ssrn.com/sol3/papers.cfm?abstract_id=7029819
  - Supports explicit leakage diagnostics and embargoed walk-forward evaluation.
- *Backtest overfitting in the machine learning era* (Knowledge-Based Systems, 2025): https://www.sciencedirect.com/science/article/pii/S0950705124011110
  - Provides controlled evidence comparing CPCV and other OOS procedures.

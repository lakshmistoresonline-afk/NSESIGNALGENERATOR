# Upstream integration record

This unified application is an original integration layer. It incorporates the research/engineering concepts identified from these public repositories rather than blindly combining their unrelated applications.

- TradeMindAI — regime/risk/quality/provenance/outcome concepts and signal-only safety boundary.
- manav363/intraday-trading-ai-india — cross-sectional ML, triple-barrier labels, purged validation, calibration, permutation tests and cost-aware research.
- Finance-broski/nse-factor-backtest — point-in-time/survivorship discipline, pre-registration, held-out testing, PSR/DSR diagnostics and factors.
- Avdhut30/BharatMarketAI — walk-forward OOS and next-bar no-lookahead evaluation.
- builditwithgk/dhan-nifty-algo-trading-lab — Indian cost stack, OOS rank persistence and paper validation gates.
- loksundar/edgelab — pessimistic event-driven backtesting and strategy-falsification discipline.
- chandewardnyanesh/kronos-nse-terminal — optional foundation-model experiment boundary.
- Raj1984/nifty-quant-lab — scanner/market-intelligence integration points.
- Omc12/Signalist — broad feature/ensemble integration points.

Important: the execution environment used to create this ZIP had no direct outbound Git clone/package access, so it could not legally/technically download and embed complete third-party repository trees. The ZIP therefore contains the unified implementation, adapters, documentation, and source references—not a falsely represented copy of every upstream file. For full upstream source trees, clone the linked repositories separately and use the integration map.
